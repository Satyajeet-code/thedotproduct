How it's made

Notice. Prompt. Ship.

Every app here is vibe coded. I describe what I want, build it with AI, and keep iterating on my own phone until it does the job.

Notice the friction

It starts with something small that keeps getting in the way, like typing a quick thought taking longer than the thought itself.

Vibe code the fix

I describe the app to Claude in plain language, let it write the code, then test it, adjust it, and prompt again until it feels right on a real device.

Ship it in the open

The source goes on GitHub, and every build is published as an APK release, so anyone can install it, fork it, or make it their own.

Install

Not on the Play Store.
Yet.

The apps are distributed as APK files through GitHub Releases. Installing one takes about thirty seconds.

sideload.md
  1. On your Android phone, open the app's Download APK link. It goes to the latest GitHub release.
  2. Under Assets, tap the .apk file to download it.
  3. Open the file. If Android asks, allow Install unknown apps for your browser.
  4. Tap Install and you're done. The full source is on GitHub if you want to check it first.
